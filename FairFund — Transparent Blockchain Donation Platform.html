Dual-Provider Strategy

Active signer calls route through BrowserProvider, while public vault reads and event logs query public Sepolia RPCs (publicnode, 1rpc, drpc). The site works immediately even if MetaMask is locked.

Pure Client-Side Execution

Zero centralized backend servers, API keys, or databases. The blockchain acts as both the authoritative state machine and the persistent event store.

Source code for FairFund.sol deployed at 0xD0D19833e211d0F483494E73822Dbb7DEB52B8D3. 

// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

contract FairFund {
    // State Variable: Stores the Ethereum address of the deployer
    address public owner;

    // Event emitted upon successful execution of donate()
    // 'indexed' keyword allows off-chain filters to query contributions by donor address
    event Donation(address indexed donor, uint256 amount);

    /**
     * @notice Constructor executes once upon contract deployment.
     * Sets the deployer's address as the immutable owner.
     */
    constructor() {
        owner = msg.sender;
    }

    /**
     * @notice Allows external users to send ETH to the contract.
     * @dev Marked 'payable' to accept value transfers. Reverts if msg.value is zero.
     */
    function donate() public payable {
        require(msg.value > 0, "Donation must be greater than 0");
        emit Donation(msg.sender, msg.value);
    }

    /**
     * @notice Queries the current ETH balance held by the contract.
     * @return Current balance in Wei.
     */
    function getBalance() public view returns (uint256) {
        return address(this).balance;
    }

    /**
     * @notice Withdraws the total ETH balance to the owner's account.
     * @dev Restricted strictly to the contract owner.
     */
    function withdraw() public {
        require(msg.sender == owner, "Only owner can withdraw");
        payable(owner).transfer(address(this).balance);
    }
}
Threat Vector Severity Vulnerability Mechanism Architectural Mitigation
Re-entrancy Attack High External contract recursively calls withdraw() before balance updates. Mitigated: Uses native .transfer() capped at 2,300 gas stipend, preventing re-entrancy state changes.
Unauthorized Withdrawal Critical Non-owner calls withdraw() to drain contract. Mitigated: Strictly enforced at EVM level via require(msg.sender == owner).
Zero-Value Spam Low Users donate 0 ETH to spam event logs. Mitigated: Guarded by require(msg.value > 0).
RPC Node Outage Medium Public JSON-RPC provider goes down or throttles requests. Mitigated: Multi-RPC failover array automatically retries secondary nodes.
Browser Origin Blocking Medium Local file:/// protocol assigns null origin, breaking MetaMask. Mitigated: Built-in local HTTP server instructions + manual inspection fallback mode.
